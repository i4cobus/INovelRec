## 选题原则

1. **一半以上带负向约束** —— H2（负向约束感知）是这个项目的核心假设，4 条 query 测不出任何东西
2. **覆盖题材空白** —— 原来 9 条完全没有玄幻、武侠、科幻、种田、无限流、末世、重生穿越、灵异盗墓、竞技、**女频**、军事谍战、商战官场、二次元、悬疑推理
3. **形状多样** —— 全是「4-5 个空格关键词」的话，模型会过拟合到这个形态，H1 就没有意义
4. **anchor 不强求** —— 没有公认代表作就留空。q003（赛博朋克）当初就是因为语料里没有对应作品而整条移除

## 三个待决

**1. 形状仍是关键词串压倒多数（35/42）。**
我没做够多样化——写成整句时容易变成我的语言习惯，而不是真实用户的搜索方式。**你才是真实用户**：句子形态你实际会怎么打？给几个真实例子我照着改剩下的。

**2. 那 10 条「不可规则判定」的负向约束是刻意保留的**，不是疏漏。
小白 / 开局无敌 / 无脑 / 独狼 / 爽文 / 搞笑 / 狗血 / 开挂——它们进不了 GRPO 的可验证奖励，但 judge 能判。这给 H2 造出**两条对照臂**：规则可验证约束 vs 纯语义约束。训练在前者上的收益能否迁移到后者，本身就是可报告的结果。如果你觉得这个对照不值得，可以把它们全删或改成可判定的。

## 追加提案（2026-08-09）：规则臂功效不足 · 待你决定

**背景。** 2026-08-09 重建了「规则可判」的判定标准（见 `docs/post_training_plan.md`
§六）。实测发现原来 22 个负向词里 17 个是**元标签**——「宠文」「种马」「金手指」这类词
读者贴在书**外面**，正文里根本不出现，关键词规则对它们的召回是结构性的零。修正后：

- 规则可判臂：**20 条 → 7 条**
- 结论方向不变且更锐利：规则臂 Δ 从 −0.100 变为 **−0.143**，语义臂 0.000 → −0.024

**问题。** 规则臂 7 条 query 里 5 条有变化，**5/5 全部改善**——但 n=5 时双侧符号检验的
**理论最小 p 就是 0.0625**。这条臂已经拿到满分，却被样本量永久挡在 p<0.05 之外。
而整个 GRPO 可验证奖励的立论，压的就是这条臂。

**一个必须先说清楚的方法论风险。** 现在我们**已经知道**规则臂是系统改善最明显的地方。
此时再去补规则臂的 query，正是当初冻结评测集要防的那种事后选择偏差。所以如果要补，
补的方式必须是**机械的、预先规定的，不能挑**。我采用的规则是：

> 对 `IN_TEXT_NEGATIVES` 里**每一个尚未被现有评测集覆盖**的叙事词，各写一条 query。
